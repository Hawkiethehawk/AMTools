# AMDA（AppMagic Data Analytics）

AMDA：基于 AppMagic 数据的全球市场分析技能。把固定的 AppMagic 周度数据整理成固定结构的全球市场分析报告，覆盖国家群组、下载与 IAP 收入、数据质量校验、趋势解读、IAA/IAP 洞察、图表生成与报告排版。

## 能做什么

- 数据质量校验：读取固定工作簿，检查周表范围与字段完整性
- 国家群组分析：全球市场按 US/T1/T2/T3 分组，细分到具体国家
- 趋势解读：按批准的数据范围分析下载与收入变化
- IAA/IAP 洞察：下载侧判断 IAA 用户规模，收入侧判断 IAP 优先级
- 图表与排版：生成五张标准图表，按报告契约核验表格与版式

不写周报；除 US 外，不以单一国家作为分析主线。

## 工作流程

1. 读取本地私有资源配置，定位数据工作簿与正式文档
2. 与用户确认截止日期与纳入的周表
3. 分析数据并生成草稿文档
4. 用户确认后覆盖正式文档

## 使用前置条件

- 飞书 lark 工具链（lark-sheets、lark-doc、lark-whiteboard 等）
- 本地私有资源配置：数据工作簿与正式文档地址只存在本机，不写入仓库
- 图表渲染所需依赖，见 scripts 目录

## 本地产物

图表与中间文件只写入 AMDA 项目文件夹内的 `output\charts`。默认项目文件夹是 AMTools 仓库中的 `skills\AMDA`，可用环境变量 `AMDA_PROJECT_DIR` 覆盖；禁止写入仓库根目录或其它位置。

## 仓库结构

- `SKILL.md`：技能入口与完整规则
- `agents/`：技能接口配置
- `examples/`：示例数据，仅演示表达方式
- `references/`：分析框架、报告契约与排版规则
- `scripts/`：图表渲染、布局校验与运行时同步脚本
- `templates/`：标准图表模板

## 开发与同步

AMTools 仓库中的 `skills/AMDA` 是唯一真源。修改随 AMTools 一起发布；运行时副本通过部署脚本注册，`scripts/skill-selfcheck.sh` 可同步到 `~/.claude/skills/AMDA`。

## 隐私

资源地址、令牌与本地配置不入库，也不出现在报告正文和提交中。
